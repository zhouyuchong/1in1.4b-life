> “站在无知之幕后，看看你将如何度过这一生。”

以中国地域差异与当代社会议题为背景的文字人生模拟游戏。随机出生、逐年经历生活，也可以主动改变职业、居住与家庭计划。

项目采用 React 18、Vite 5 和 Tailwind CSS，纯前端运行，无需后端或数据库。城市权重、金额与终局排位属于游戏中的简化设定；当前仓库没有完整的统计来源校准链路，不应将游戏结果视为真实人口分位或个人财务预测。

## 🌟 核心特色

1. **随机出生与地域差异**：包含 346 条地域记录，涵盖地级市、州、盟、直辖市圈层及部分合并区域。按配置权重抽取出生地，再依据配置的城镇比例生成城乡户籍。
2. **每年多段经历**：0～85 岁有独立年度数据目录。正常年度抽取 2～3 条不重复事件，优先保留年龄或路线相关经历；关键节点、重大抉择和后续事件丰富人生记录，同龄记录合并展示。
3. **选择影响后续剧情**：租房人生不生成房贷账单，丁克或暂缓生育不会被动出现奶粉费、子女和孙辈剧情；职校、务工和大学路线按各自经历推进。
4. **主动求变**：16 岁起可主动发起学习、求职、考编、创业、调整居住、重议生育计划、健康、旅行、礼物、兴趣爱好、社交或恋爱行动。选项按年龄与当前状态开放，每年可完成一次行动；取消不扣费、不消耗机会。
5. **具体金额与年度账本**：展示可用余额、住房估值和剩余贷款，预览选择的金额变化，展开年度收入、生活费、租金、还款和育儿支出。金额不再受 0～100 分上限限制。
6. **结局与分享**：健康耗尽或达到寿命上限后，生成称号、财务账本和估算指标，可下载 PNG 海报。

## 🎮 如何体验

点击“开始投胎”生成角色，然后点击“度过下一年”或按空格推进。自动模式每秒推进一年，遇到年度抉择会暂停等待选择，完成后继续。

16 岁起可在“主动求变”中打开事件弹窗。行动不推进年龄，也不会重复结算当年的工资或账单；部分行动有成功与失败分支，部分会在下一年触发后续事件。发起行动时自动推进会暂停，完成后可手动恢复。

| 主动行动 | 开放条件 | 对后续人生的影响 |
|---|---|---|
| 进修学习、照顾身体 | 16 岁起 | 影响认知、健康、心力；进修次年有成果反馈 |
| 求职、考编、创业 | 18～59 岁且当前不在读；备考期间也可转向；全职备考最晚 37 岁发起，38 岁未上岸必须转向 | 可能改变职业与后续年收入；备考不会立即获得编制 |
| 调整居住 | 18 岁起 | 租房、买房或卖房结贷，改变资产、贷款和后续账单 |
| 重议生育计划 | 22 岁起、已婚且尚未生育 | 仅在明确选择生育后开始计算养育支出 |

角色和进度保存在当前页面内存中，刷新页面或重开会重新开始。

### 大胆一搏 · Bold & Risk

18岁起，在「主动求变」中进入「大胆一搏」。按年龄、学历与就业状态开放，和其他主动行动共用每年一次机会；取消不扣钱、不消耗机会。每类尝试单独记录次数，考试和面试经验可有限提高后续胜算，彩票每次独立开奖。

| 事件 | 开放条件 | 结果与后续影响 |
|---|---|---|
| 高考复读 | 18～21岁，高中学历、未在读；当年首次升学后也可改选复读 | 花15000元，另预留30000元生活费，暂停工作，次年放榜。更好的本科读4年，大专读3年，失败可再试或就业；本科成功路线毕业后企业与公共岗位基础年薪增加12000元 |
| 考研再战 | 21～35岁，本科毕业、未在读或备考 | 在职备考6000元并保留工资；全职备考12000元、另预留30000元生活费，无工资。次年录取后全职读研3年，毕业取得硕士学历，后续企业与公共岗位基础年薪增加24000元；失败可再战或转向 |
| 跳槽 | 22～55岁，已就业、未在读或备考 | 拿到offer再离职花1000元，成功涨薪20%，失败保留岗位；裸辞冲刺花3000元、另预留30000元生活费，成功涨薪40%，失败待业。新薪资持续进入以后年度账本，换职业或退休后重新计算 |
| 彩票 | 18岁起 | 每次20元，90%未中奖、9.9%中10元、0.0999%中1000元、0.0001%中100万元，奖金直接入账；重复尝试不提高中奖率 |

所有概率、薪资与奖金都是游戏设定。学历只在完成学制后更新；备考转向其他职业会取消原考试结果。还债暂停会同时顺延考试与毕业时间。毕业抉择中的考研选项也使用这套考研规则。

## ✍️ 如何扩展与新增某一年的事件或抉择？

仅修改文案或使用已有字段时，可以直接编辑对应年份的 JSON。当前页面会缓存已加载年份，修改后需重新加载页面；Docker 部署还需要重新构建镜像并替换容器，详见 [部署指南](deploy.md)。

如需让修改在重新生成后保留，应同时维护 `scripts/generate_ages.js` 或 `scripts/life_content.js`。新增状态值或引擎规则则需要修改相应代码并重新构建。

### 1. 扩充日常文本：`events.json`
```json
[
  {
    "id": "e_age18_custom",
    "condition": { "isRural": true },
    "text": "村里为你挂起了祝贺高考的横幅，同村的长辈纷纷赶来道喜。",
    "effect": { "sanity": 5 }
  }
]
```

### 2. 扩充重大转折：`choices.json`
```json
[
  {
    "id": "choice_custom_sample",
    "title": "事件标题",
    "description": "事件详细社会背景与起因",
    "sourceCase": "真实社会案例/新闻出处",
    "condition": {
      "minKnowledge": 50
    },
    "options": [
      {
        "text": "选项一描述",

    ]
  }
```

## 人生状态与剧情衔接

角色的 `lifeState` 保存当前事实，`tags` 仅记录历史经历。事件、抉择和选项均可通过 `condition.lifeState` 设置前置条件，选项和事件通过 `stateEffect` 更新事实。条件中的数组表示“任一值匹配”，多个字段之间为“并且”。

| 字段 | 状态值 |
|---|---|
| `education`（已完成学历） | `none`、`primary`、`junior_high`、`high_school`、`vocational`、`college`、`bachelor` |
| `schooling`（当前在读） | `preschool`、`primary`、`junior_high`、`high_school`、`vocational`、`college`、`university`、`none` |
| `career` | `none`、`worker`、`private`、`public`、`self_employed`、`preparing`、`retired` |
| `careerTrack` | `general`、`directed_public`、`public` |
| `marriage` | `single`、`married` |
| `parenthood` | `none`、`parent`、`childfree`、`deferred` |
| `childBirthAge` | 实际生育时的角色年龄，未生育为 `null` |
| `housing` | `family`、`renting`、`mortgaged`、`owned` |
| `mortgageEndAge` | 还清贷款时的角色年龄，或 `null` |
| `hasGrandchildren` | `true` / `false` |

例如，房贷事件只对正在还贷的人生生效：

```json
{
  "text": "每月住房贷款如期扣款，你认真安排收支。",
  "condition": { "lifeState": { "housing": "mortgaged" } },
  "effect": { "sanity": -2 }
}
```

例如，29 岁生育选项应写入 `"stateEffect": { "parenthood": "parent", "childBirthAge": 29 }`，子女剧情则要求 `"condition": { "lifeState": { "parenthood": "parent" } }`。丁克与暂缓生育不会自动转为父母；单身路线不会触发生育抉择；照料孙辈的选项要求已有子女且子女至少 22 岁，选中后才记录孙辈状态。`minChildAge` / `maxChildAge` 可进一步限制子女年龄。

成年后可选择相识、恋爱、沟通与分手，28 岁的婚姻选择仅对已有恋爱关系的角色开放；也可以在主动经营感情时决定结婚。27 岁购房选项设定为 30 年按揭，57 岁转为已还清。学历在完成相应学制后更新，备考不会自动获得学历或编制。60 岁进入晚年阶段是游戏的简化规则。

推进年份时先处理入学、毕业和贷款到期，并公布到期的考试或进修结果，再筛选本年的抉择与剧情。做出抉择后，会按更新的状态重新筛选当年配套事件。数值门槛在界面与引擎两处使用同一规则校验。

年度 JSON 可直接编辑；如果需要重新生成数据，请同时修改 `scripts/generate_ages.js` 或补充规则 `scripts/life_content.js`，再运行 `npm run generate:ages`，避免覆盖手动修改。运行 `npm test` 检查跨年份剧情回归。

### 多事件、主动求变与金额账本

- 1～17 岁每岁新增 3 条独有生活片段，共 51 条；在 4、7、8、11、12、13、14、16 岁补充日常抉择，每组 3 个选项。成年后也有更多日常抉择，抽取普通叙事时避开最近五年的相同文本。
- 新增旅行、送自己礼物、培养爱好与社交行动，均提供免费方案。成年后还可主动经营感情，相识后才会开放结婚选项。
- 全职备考者每年都可重新选择，免费投简历或做过渡工作不受余额限制。游戏内最晚 37 岁发起全职备考，38 岁公布最后结果，未上岸则转向求职、过渡工作或创业。
- `lifeState` 记录父母存世状态与具名朋友：父母的告别年龄在开局生成；朋友会留下结识年龄，后续可相聚、主动联系，晚年也会出现一次性的离世告别。

- 每年抽取 2～3 条不重复的有效事件，优先保留年龄或路线相关经历，关键节点必定出现。重大选择和年度收支额外记录；同龄记录在界面合并展示。
- 16 岁起出现“主动求变”，每年可完成一次行动。取消不扣费、不消耗机会；行动不推进年龄，也不重复结算当年工资与账单。求职、创业存在公开的成功/失败分支，进修和全职考编可在次年收到后续事件。主动改变职业、居住、生育计划后，之后的事件与账单随状态更新。
- `finances` 记录 `cash`、`propertyValue`、`mortgageDebt`、`mortgageAnnualPayment`，金额单位均为人民币元；`mortgageStartAge` 记录购房时的角色年龄。界面显示余额、房产和剩余贷款，选择预览与历史记录显示具体金额变化。余额为负表示必须处理的资金缺口，会弹出资金危机抉择，阻止继续正常推进。网贷与家人借款另记为负债，计入终局净资产。
- 金额属于游戏设定。初始资金按家庭背景为 1.5 万／6 万／20 万／80 万元；年收入按职业设为 6.6 万～10.8 万元，退休收入为 3.6 万元，成年人基础生活费为 3 万元。租房每年 1.8 万元；示例住房估值为 90 万元、首付 18 万元、贷款 72 万元，使用不含利息的 30 年等额本金简化规则，从购房次年开始按年还款。当前模型不模拟税收、通胀、房价波动或投资收益，也不代表现实预测。
- 只有实际养育子女才计提养育支出：按 `childBirthAge` 计算，未满 3 岁每年 1.8 万元、3～17 岁每年 1.2 万元。暂缓与丁克不会被自动扣奶粉费；选择改变生育计划后才开始记录。
- 新事件优先使用 `cashEffect` 明确收支，`financeEffect` 更新房产与贷款，`minCash` 设置最低可用余额。旧事件的 `effect.wealth` 保留兼容：每点在 0～5 岁折算 1000 元、6～17 岁折算 2000 元、18 岁起折算 3000 元；`cashEffect` 存在时优先使用，避免重复扣款。旧的财富分数仅保留为游戏内部指标。
- 年度账单统一结算收入、生活、房租、房贷和子女支出；仅描述这些账单的叙事事件不重复扣款。`followUp` 用于安排下一年后续事件，支持前置条件与 `outcomes` 概率结果。
- 年度数据请求带内容版本并禁用浏览器缓存，Nginx 的 `/data/` 也要求重新校验。部署新版时需同时更新 JS 与 JSON；内容结构发生改变时同步更新加载器的内容版本标识。

### 资金危机与还债

- 余额为负时，先选择网贷、向家人借钱或暂停原计划兼职；金额不足以补齐缺口时继续处理，不能直接跳到下一年。无抵押净负债（网贷＋家人借款－可用余额，最低为零）达到家庭背景对应的上限（低保特困3万元、工薪温饱10万元、小康中产30万元、高净值富裕100万元），或网贷逾期满一年，只能进入强制还债。住房贷款另行结算，不单独触发该门槛。
- 网贷仅对成年人开放，每次最高5万元，未清偿前不可再借。借款次年到期，年息20%（向上取整到元）；借款当年不计息，到期后每年按未偿欠款计息。年度账单后用正余额还款，不足部分保留为欠款；逾期扣健康和心力，逾期满一年加重扣减、永久关闭网贷资格并强制打工还债。
- 家庭免息借款的累计额度依次为：低保特困5000元、工薪温饱3万元、小康中产15万元、高净值富裕60万元。归还不重置累计额度；父母均离世后不再提供新借款。年度结余先偿还到期网贷，再归还家人借款。
- 兼职占用下一整年，暂停原有工资、学业、备考与后续事项，不开放主动行动；结束后可重新安排。学业按暂停年数推迟，已安排的考试、课程和兴趣反馈顺延。强制还债持续到资金缺口与两类借款全部清偿。
- 打工年收入9.6万元，成年人基本生活费降为1.8万元，房租、房贷、育儿费用照常；打工每年扣健康3、心力2。16岁以下的困境改为家庭紧急增收（每年4.2万元），不开放网贷或安排儿童进厂。退休、房贷和亲友告别按实际年龄推进，不随学业暂停。
- 以上均为游戏规则；核心参数集中在 `src/services/debtRules.js`，资金危机选项与年度债务结算在 `src/services/debt.js`。不模拟现实法律意义上的破产程序。

## 🚀 本地开发与运行

```bash
# 1. 安装锁定版本的依赖（Node.js 18 或更高版本）
npm ci

npm run dev

npm test

# 4. 编译生产打包
npm run build
```

```bash
# 重新生成 0～85 岁的年度 JSON（覆盖现有文件）
```
